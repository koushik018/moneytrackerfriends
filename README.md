# TrackMe

A private money tracker for Android. Banks, cards, UPI, cashback, bills, IPOs and investments in one place.

**Your data stays on your phone.** There is no server and no account. Nothing is uploaded.
This repository contains only the app code – no personal data.

## Install (Android)
1. Open the **Releases** page of this repository and download the newest `TrackMe-…apk` using Chrome.
2. Open the file. If asked, allow *Install unknown apps* for Chrome.
3. Open TrackMe and follow the short setup. Pick only the banks and cards you use.

## Update
Open **Settings → About → Get the newest version**, or download the newest APK from Releases and install it over the old one. Your data is kept.

## Back up
Settings → Security & privacy → Make encrypted backup. Keep the file and its password somewhere safe. Restore it from the first screen or Settings on a new phone.

## iPhone
Open the web version (see the install page) in Safari → Share → Add to Home Screen.

See `FEATURES.md` for how everything works.
